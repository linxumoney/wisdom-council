> 向世界上最有智慧的人提问，让他们替你辩论。

巴菲特 × 芒格 × 稻盛和夫 × 彼得·林奇 × Naval × 达里奥 × 彼得·蒂尔——7位智者同台，碰撞你的问题。

## 🚀 快速开始

### 方式一：Claude Code（推荐）

```bash
# 安装
cp -r wisdom-council ~/.claude/skills/

# 在 Claude Code 中触发
/council 我应该投资比特币吗？
/智者 如何判断一个生意值不值得做？
```

### 方式二：复制 Prompt

把 `SKILL.md` + `references/thinkers.md` 的内容贴进任意 AI 对话框，直接使用。
